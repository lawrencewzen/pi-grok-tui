pi tui · 设计初稿

Grok 风 pi TUI

配色直接继承你 Ghostty 的 Grok 主题（画布 #141414、暖调低饱和 palette），在它之上按 Grok 的语言组织：灰阶做层次、白当强调色、彩色只在有语义时出现。 这一版不只是配色——同时用扩展接管 header、footer 和编辑器：启动横幅的结构留下、材质换掉，footer 压成三段，spinner 保持 pi 原样。

本页用这套配色和你的终端字体（Maple Mono NF CN）渲染，所见即终端所得。标了「已装」的部分都已实机跑过，实机推翻的决定也记在原处。切换系统外观可预览浅色版。

04 · 谁管什么

每个区域能改到什么程度

这是上一版"看不出差别"的原因：pi 的主题只有 51 个颜色 token，碰不到任何布局。下面标了每块归谁管。

header 扩展
结构留下，材质换掉。方块 π、右栏命令提示、两栏布局都保留；圆角框换直角 hairline、彩色换白、tagline 收进灰阶。另外把原版没播的动画补上：包的 README 宣传"16 帧变色动画"，但 header.ts 写死了 frame = LOGO_FRAMES.length - 1——只渲染最后一帧，22 帧数据是死代码。我们把它真正跑起来，单色重放，启动时播一次。
启动清单 内核
那段 [Skills] [Prompts] [Extensions] [Themes] 是 pi 自己画的可展开区块，扩展替换不了，只能用 quietStartup: true 静音——安装脚本已经设上，--uninstall 会删掉这个键。信息没有丢：getCommands() 带 source: "extension" | "prompt" | "skill"，header 右栏改成从这里取真实命令，优先显示你自己装的 skill 和 prompt，并给出总数。诊断和冲突警告不受静音影响，照常显示。
footer 扩展
双行 starship 压成单行三段：cwd | 模型 | 剩余上下文，| 分隔、全 dim 灰、无 Nerd Font 图标、无进度条方块。git 状态、runtime 检测、token 上下行、花费、TPS 弹条全部去掉。
编辑器 扩展
去掉圆角和左侧彩色导轨。改成方角单线细框，左侧一个白色 ›。边框颜色继续承载 thinking 等级和 bash 模式。
加载指示器 扩展
不换成呼吸点，但换了帧。pi 原生的 ⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏ 是两点在 2×4 braille 点阵里绕圈，实测（Maple Mono NF CN，1/1000 em）重心在 340–553 之间移动、跳动 213 ≈ 字号 21%，所以 spinner 相对 working 文字上下浮。改用 ⣾⣽⣻⢿⡿⣟⣯⣷——八点亮七点、转的是缺口，每帧包围盒相同，重心恒定 340。
也试过方形的 ◧◩◨◪（600×600 正方形、同样零抖动），但 Unicode 里这类方形部分填充字符只有 4 个，帧数减半后动画明显更跳，观感不如点阵转圈——留作 spinner: "square" 选项。
working 行 扩展
Working 12s · 3.4k tok，每 250ms 刷新。秒数从 agent_start 计到 agent_end，跨整个 agent 运行。
token 这里有个坑：走 OpenAI 兼容协议的 provider（DeepSeek 等）只在最后一个 chunk 里返回 usage，所以一整条回复流完之前报告值都是 0，数字会僵住然后突然跳。用 estimateTokens() 按文本估算填掉这个空档，显示成 ~712 tok；provider 的真实数字一到就接管，~ 消失。会覆盖 pi-working-phrase 的随机词。
工具输出 扩展
启动时用 setToolsExpanded(false) 折叠，只留标题行。这只设初始状态——pi 内置的 Ctrl+O 照常切换，不抢它。
用户消息 主题
块状灰底是 pi 内核画的，扩展改不了结构——只能把底色定成 #16181a，接近 Grok 那个几乎与背景融合的气泡。
工具框 主题
三态背景（等待 / 成功 / 失败）只能换颜色。这里用极低饱和的中性、暗绿、暗红，压到几乎看不出色相，只在余光里能分辨状态。
语法高亮 主题
函数名用白、关键字柔蓝、字符串柔绿、数字淡紫，其余走灰阶。整块代码远看仍是单色，凑近才有结构。
消息流布局 内核
缩进、换行、工具框的框架结构由 pi 自己渲染，扩展 API 够不到。真要动得改 pi 源码——不建议。

06 · 色板

三条规则撑起整套配色

强调色是白不是彩色；层次靠灰阶不靠色相；彩色只在有语义时出现。所有彩色都取自你 Ghostty 主题的 palette，所以 pi 跟同一个终端里的 ls、git、vim 是一套颜色。

画布和字体都不归主题管。pi 只画文字和局部色块——背景是 Ghostty 的 background = #141414，字体是 Ghostty 的 font-family = Maple Mono NF。所以这套主题是照着你的终端校准的：块背景 #1a1a1a / #1e1e1e 只比画布亮一到两档，线用你的 selection 色 #333333，琥珀取自你的光标色 #d8b173。换终端主题的话，这套要重新校。
