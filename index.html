What it does

装了它，pi 长出 Grok 的骨架

装什么、不装什么，清清楚楚。结构是 pi 内核画的，只能改颜色；能改布局的地方，这里都做了。

Header

直角框 + 白色 π + 启动动画

直角 hairline 框、白色方块 logo、右栏命令提示。动画数据来自 pi-open-tui，那个包只渲染最后一帧——这里把它播出来，22 帧 × 70ms，并换成灰阶。

Footer

单行三段状态栏

cwd | 模型 | 剩余上下文，一段一行，默认纯文字。gitBranch / thinking / cost 可选，Nerd Font 图标可选。

Editor

方角闭合细框

pi 默认只有上下两条横线，这里补成闭合方框。边框色仍随 thinking 等级和 bash 模式变化，不牺牲语义。

Cursor

光标还给终端

剥掉 pi 的反显方块，交给终端自己画——尊重你的 cursor-style。想要方块？cursor: block 切回来。

Completion

补全面板向上展开

输入框留在原地，面板往上长。面板本身仍由 pi 渲染，只是方向换了。

Spinner

重心恒定的 braille 转圈

⣾ 八点亮七点，转的是缺口

pi 原生那组两点绕圈，字形重心上下跳动约字号的 21%；braille 帧包围盒恒定，抖动归零。实测对比见下。

Working

working 行实时统计

Working 12s · 3.4k tok，秒数和输出 token 每 250ms 刷新。秒数跨整个 agent 运行计时，token 取流式 usage。

Tools

工具输出启动时折叠

只设初始状态，Ctrl+O（pi 内置）随时展开。想全开？collapseTools: false。

Startup

启动清单静音

quietStartup 收起 pi 那段 [Skills] [Prompts] [Extensions] 清单；header 右栏从 getCommands() 取真实命令补上。

Theme

不是凭空配的：继承自 Ghostty 的 Grok 主题

深色版背景 #141414、前景 #e1e1e1、光标琥珀 #d8b173，功能色直接取自那套 palette。pi 和同一个终端里的 ls、git、vim 是一套颜色。

Install

安装 & 运行

一条脚本装完主题 + 扩展，并自动把抢同一组 API 的 pi-open-tui 置为 enabled: false。装完重启 pi。

install.shbash
$ ./install.sh              # 主题 + 扩展，并把 pi-open-tui 置为 enabled:false
$ ./install.sh --themes     # 只装主题，不动界面
$ ./install.sh --uninstall  # 全部还原（pi-open-tui 会翻回来）
~/.pi/agent/settings.jsonjson
{ "theme": "grok" }

注意加载顺序：~/.pi/agent/extensions/ 是自动发现目录，排在 settings.json 里的扩展之后——那里任何调 setHeader/setFooter/setEditorComponent 的文件都会覆盖本扩展。安装脚本会扫描并列出这类文件。

Config

一块 JSON 控制所有行为

~/.pi/agent/grok-tui.json，改完 /grok-tui reload 生效。

~/.pi/agent/grok-tui.jsonjson
{
  "enabled": true,
  "header": "full",          // full | plain | logo
  "headerAnimation": true,    // 启动时播一次组装动画
  "tagline": "Let's build something great",
  "commandTips": 4,            // 0 隐藏整个右栏
  "editorFrame": "box",          // box | lines
  "cursor": "bar",              // bar | block
  "completion": "above",        // above | below
  "spinner": "braille",          // braille | square | pi
  "workingStats": true,
  "workingLabel": "Working",
  "collapseTools": true,
  "icons": "off",              // off | nerd | auto
  "footer": { "gitBranch": false, "thinking": false, "cost": false }
}

full · plain · logo

spinner

Design

三条规则，一套颜色

换终端主题的话这套要重新校——但规则不变。

  • 01强调色是白，不是彩色。Grok 的克制来自克制本身——该亮的地方用 ink，不用大红大绿抢。
  • 02层次靠灰阶，不靠色相。块背景只比画布亮一到两档（#1a1a1a / #1e1e1e），线用终端的 selection 色 #333333。
  • 03彩色只在有语义时出现。错误红、成功绿、thinking max 用光标的琥珀——功能色直接取自 Ghostty Grok palette，和终端的 ls、git、vim 同源。
Spinner 为什么换帧

两点绕圈 vs 缺口转圈

pi 原生 ⠋⠙⠹… 是两点绕圈：亮点在动，字形重心跟着上下移，跳动约字号的 21%。braille 版 ⣾⣽⣻… 八点亮七点、转的是缺口，包围盒恒定，抖动归零。方形版 ◧◩◨◪ 是正方形，但 Unicode 只有 4 帧，动画更跳。

Statistics

working 行的数据从哪来

秒数：agent_start → agent_end 跨整个 agent 运行计时。token：message_update 的 usage.output，已结束的累加进 settled、正在流的记在 streaming。能不能实时跳动取决于 provider 是否在流式时报告 usage。

Limits

两件主题管不了的事

画布颜色属于终端，pi 只画文字和局部色块；字体属于终端——这套配色是照着 Maple Mono NF CN 校的，Nerd Font 图标也依赖它。
